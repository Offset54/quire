# 0018. Internationalized UI strings

- Status: Accepted
- Date: 2026-10-08

## Decision

- Every UI string lives in a message catalog (`apps/desktop/src/i18n/en.json`) and is formatted with ICU MessageFormat through `@formatjs/intl` 6 (MIT).
- `t(id, values)` is typed against the English catalog's keys, so a missing id is a compile error.
- The locale comes from `navigator.language`, falling back to English.
- Core-side text processing (segmentation, line breaking) will use ICU4X (Unicode-3.0, approved).

## Alternatives considered

| Option | License | Why not |
|---|---|---|
| i18next | MIT | Not ICU MessageFormat by default (§9 asks for it) |
| Fluent | Apache-2.0/MIT | Different syntax from §9's ICU MessageFormat |
