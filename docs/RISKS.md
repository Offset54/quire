# Risk register

Likelihood (L) and impact (I) are rated High, Medium or Low. "Retires" is the earliest milestone whose evidence can close the risk. Reviewed at every milestone report.

## Watch list

- **No license on a public repo.** Since 2026-10-13 (ADR-0025) the code is public with no `LICENSE`, so all rights reserved. Choosing a license is the user's call.
- **License creep.** ICU4X (Unicode-3.0) and the bundled fonts (OFL-1.1) aren't on §0's list. cargo-deny will catch new cases.
- **EMF/WMF and chart coverage** in real PPTX decks (M5).
- **Footnote back-links in table pieces.** References to one note from two pieces of the same large table get the same back-reference id (ADR-0030); the note's back-links then lead to the first.
- **Edits during a save are refused.** An edit that reaches the core while a save runs gets "busy" (M1 behaviour); a pasted image's link that arrives then is lost, though the image is stored. Queue edits behind the save instead (M7 at the latest).
- **Hybrid CPUs.** On P/E-core machines, "physical cores minus one" may overcommit slow cores (M3).
